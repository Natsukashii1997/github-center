# 已定内容登记表

所有者选定、定稿或验收一个界面、交互、文案、数据格式、流程或规则的当轮，由做这一轮的 agent 在下面加一行，并在当轮交接里写明「已登记 DECIDED.md」。以后判断「这处算不算已定」先查这里；要改登记过的内容，先单独问所有者。

- 一行一项，只增不删。所有者同意改掉某项后，新加一行，旧行的备注写「已被 <日期> 那行取代」。
- 提交号写定下来时的那个提交；没有界面的写「无截图」；在哪定的写得能查到（会话日期、PR 或 issue 编号、文档位置）。
- 没登记不等于没定：对话、PR、issue 里所有者明确说过「就这个」「定了」的，照样算已定，发现了就补登记。
- 视觉细节不在这里展开：白雾重设计的全部定稿决定以 [docs/design/白雾定稿.md](design/白雾定稿.md) 为准，本表只登记「有这么一份定稿」。
