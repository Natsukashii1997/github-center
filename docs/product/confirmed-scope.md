# 已确认产品范围

来源：本项目用户对话中的明确决定和2026-10-22起的研究记录。未保留完整题干的Q1/Q2等选项不凭编号推断；没有把推荐路线或隔离验证写成已实现功能。

## 用户与目标

先供本人使用，未来邀请小团队成员。在一个地方快速发现值得关注和尝试的GitHub项目，减少反复搜索与依赖自媒体榜单。

## 确认的功能

| 功能 | 已确认含义 |
|---|---|
| 官方热门与累计榜 | 官方GitHub Trending与历史累计Star榜是不同来源和口径，分别展示 |
| 全站涨星榜 | 保持全站目标，按GitHub官方统计日做近1/7/30日榜，每天更新；首版Top20包含末位并列 |
| 连续领先展示 | 一直第一就持续排第一，不为新鲜感人为轮换 |
| 项目类型 | 分类需要包含Skill；其他分类细项在正式规格中核对 |
| 收藏 | 只需一个“自己感兴趣”的收藏能力，收藏随账号走 |
| 安装指令 | 点击按钮复制项目安装指令，再交给自己的Agent安装；不是网站远程控制电脑自动执行 |
| 历史榜单 | 可以回看历史榜单 |
| AI日报 | 基于采集事实生成中文日报；完整输入口径与验收需结合真实榜单继续核验 |
| 项目对比 | 支持多个项目对比；单项目增长分析不作为必需功能 |
| 账号与团队 | 先私人中心，后续按邀请使用；具体角色、权限和认证方案尚未实现 |
| UI与生成思路 | 参考AIHOT的整体UI风格和底层生成、缓存、组织方式，结合开源参考聚合功能 |

## 运行与成本

优先现有电脑，不新增费用；既有登录和可用额度不等于无限免费。没有授权公开仓库、购买模型API、开通云托管或上传本机凭据。本次另有明确授权创建并上传项目资料至私有GitHub仓库，真实运行数据仍保留本机。

## 数据完整性

全量分片分页、两轮候选、固定日桶评分、新鲜榜单边界复核、Top20含并列、缺失不补零。公开仓库含fork；索引可见范围和非原子采样限制须如实说明。官方统计日口径已确认，但精确UTC映射和“统计日已完结”的技术证明尚未通过。

## 功能关系

发现（热门/累计/涨星）→阅读项目摘要与事实→对比和历史回看→收藏→复制安装指令交给Agent。AI日报使用同一批采集事实帮助快速浏览；账号承载个人收藏，未来邀请层管理团队访问。

这是一条已确认方向的整理，不是已批准的详细技术规格或页面版本。数据核心闭环验证后再按Matt流程推进正式规格、视觉与实现。
