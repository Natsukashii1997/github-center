# Triage Labels

| 规范角色 | 仓库标签 | 含义 |
|---|---|---|
| needs-triage | needs-triage | 待判断和分流 |
| needs-info | needs-info | 等待必要信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由Agent执行 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 已决定不处理 |

Skill提到上述角色时使用对应标签。不要把“代码已改”直接当作需求已验收。
