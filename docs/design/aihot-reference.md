# 视觉参考：AIHOT 整体风格（#12 v2 的共同约束）

所有者 2026-10-23 明确：视觉以 [AIHOT](https://github.com/KKKKhazix/AIHOT)（线上 https://aihot.news）的整体风格为参考，要求克制、高级、优雅、美观。本文件是 v2 三套候选的共同约束；三套只在布局与动效编排上不同，不在色板和气质上分叉。

来源：AIHOT `apps/web/app/app.css`（设计变量注释原文为“warm off-white paper, ink text, one teal accent, hairline borders, no gradients”）、`docs/assets/shots-*.png`、线上首页与 `/hot` 热点榜（2026-10-23 在 1440×900 下查看）。

许可：AIHOT 代码为 MIT；其 NOTICE 把 AIHOT 名称和 Logo 排除在授权外。本项目只借鉴风格与设计变量的取值思路，名称用“GitHub 快速中心”，标识自己画，不出现 AIHOT 的名称和 Logo。

## 气质

- 纸面感：暖白底、墨色字、一个青色强调，其余全靠字重、字号、留白和发丝线分层。
- 安静：不用渐变、辉光、大面积饱和色、装饰性假编号；阴影只到“看得出浮起”为止。
- 数据说话：数字用等宽或等宽数字字形，大数字是页面上最重的元素；趋势用细线小图，纵轴从零开始、线性比例。

## 字体与字号

- 中文与正文：系统字体（苹方），不加载外部字体。正文 14px / 1.5，说明 12–13px。
- 编号、时间、小标签、数字：系统等宽字体，`tabular-nums`；小标签可大写加字距（如 `NO.01`、`OFFICIAL · DAILY`）。
- 标题：页面标题 24–28px 粗体；首屏大标题 40–48px 粗体，第二行可用强调色。

## 形状与线

- 圆角只用 5 / 8 / 10 / 12 / 14 / 16 六档（标记 / 控件 / 行 / 卡片 / 面板 / 抽屉与弹窗），胶囊用全圆。
- 边框 1px 发丝线；卡片阴影 `0 1px 2px` 极淡，悬停略加深；深色模式不用阴影。
- 招牌插图：许多细线汇聚到一个圆形节点（✦），再分出几条青色线；只作信息表达，不作背景装饰。

## 动效

以下按 AIHOT `app.css` 的实际做法写定（2026-10-23 T1a 审查后澄清）：

- 进场和状态切换：120–280ms，曲线 `cubic-bezier(.25, 1, .5, 1)`（ease-out-quart）。
- 退场：140–200ms，ease-in，比进场短。
- 悬停：颜色、底色、边框过渡 120–160ms；卡片悬停阴影 200ms。
- 位置和大小的变化只动 transform、opacity、clip-path；不动画 width、height、padding、top、left。
- 词汇只有：淡入并上移 4–6px、折叠展开、0.96→1 轻微缩放、抽屉从边缘滑入、图标轻弹（0.7→1.08→1）、勾号弹出（0.6→1.05→1）、细线从左到右揭开。
- 例外两项：首屏招牌插图进页时揭开一次，可到 700ms，之后不再重播；加载骨架的呼吸 1.6s 循环，是唯一的循环动画。
- 系统开启“减少动态效果”时全部改为直接切换，包括用脚本触发的动画。

## 不做

渐变、辉光、Fraunces 等装饰字体、破折号“—”、非线性或从非零开始的数据比例、让后面名次比前面更显眼的强调。
