# 视觉能力与交互矩阵（#12 输入）

来源：规格 #1 与 docs/product/requirements-regrill.md 的最终回放。视觉风格以 AIHOT 整体风格为参考，约束见 [aihot-reference.md](aihot-reference.md)。视觉方案只决定外观和动效，不改变以下页面、数据、控件和状态。只做电脑版（最小宽度 1280px，主测 1440px）。

## 页面与数据

| 页面 | 区域 | 数据驱动内容 | 控件与结果 |
|---|---|---|---|
| 全局 | 顶部导航 | 当前用户名；数据更新时间、统计到哪一天 | 涨星榜（首页）／其他榜单／日报／我的收藏／退出 |
| 首页：涨星榜 | 窗口切换 | 近 1／7／30 天 | 切换窗口 → 列表替换，有过渡 |
| | 分类筛选 | 全部＋9 个分类 | 选分类 → 列表重排；不足 20 个时显示实际个数和说明 |
| | 榜单 | 名次（并列同名次）、头像、owner/repo、一句话简介、窗口新增 Star、当前总 Star、分类标签（≤2） | 点行 → 项目页；行内收藏按钮 → 收藏/取消 |
| | 状态 | 正常／可能不完整（含原因）／更新失败（显示上次成功日期） | 无 |
| 其他榜单 | 榜单切换 | 新项目榜／官方热门榜（日／周／月）／累计高星榜 | 切换 → 列表替换 |
| | 榜单 | 同首页；新项目榜加“创建于”；官方热门榜保持官方顺序 | 同首页 |
| 日报 | 头部 | 日期、统计日、整体概览（一段文字） | 无 |
| | 三个窗口 | 近 1／7／30 天各前 10，同一项目只介绍一次（其余位置写“见上”） | 点项目 → 项目页 |
| | 背景 | 有证据的 Release 等，附链接 | 外链 |
| 项目页 | 头部 | 头像、owner/repo、分类、总 Star、近 1／7／30 天新增、原项目链接 | 收藏项目；打开 GitHub |
| | 简介 | 干什么（一句）、解决什么具体问题（一句） | 无 |
| | 使用条件 | 文档写到的付费／账号／密钥／环境；没有就不显示该块 | 无 |
| | Skill 列表 | 每个 Skill 的名称、用途 | 收藏单个 Skill；复制该 Skill 的安装指令 |
| | 安装指令 | 目标 AI：Claude Code／Codex；范围：整个仓库／某个 Skill | 复制 → 成功提示 |
| | 状态 | 简介生成中 | 无 |
| 我的收藏 | 列表 | 项目与 Skill 两类，显示收藏时间 | 点 → 项目页；取消收藏 |
| | 空状态 | 还没有收藏 | 去看涨星榜 |
| 登录 | 表单 | 用户名、密码、错误提示 | 登录 |

## 状态清单（每套方案都要表达）

加载中、空、最长中文简介、超长 owner/repo、并列名次、五位到七位数字、可能不完整、更新失败、简介生成中、分类不足 20 个、收藏/取消、复制成功、登录失败。

## 必须体验的动效

切换时间窗口、切换分类、进入项目页、收藏、复制安装指令。

## 不变的约束

不加推荐、对比、历史回看、搜索、手机适配；不显示事件计数；数字均为 GitHub 官方数据；榜单排序不可被视觉强调改变（比如不能把第 5 名做得比第 1 名更显眼）。
