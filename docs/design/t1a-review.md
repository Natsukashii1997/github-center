## T1a 结论：REVISE（修改后复审）

设计判断：个人每日速览类产品界面，电脑端，单一中文用户；目标是好看、动效完美。参考档位：版式变化 6、动效 7、密度 5。

### 共同问题
1. 没有照顾“减少动态效果”系统设置。**已修**：data.js 统一加了 CSS 降级，并让 transition() 在该设置下跳过 View Transitions。A 的 countUp 和 B 的 FLIP、星空仍需各自判断 `GC.reduced()`（**待改**）。
2. 缺失值显示为破折号“—”，改为“未上榜”（三套都**待改**）。
3. 每套只有一种明暗主题：标为 DEFERRED，到 T1b 时补齐，或由所有者决定只要一种。
4. 字体目前用 Google Fonts 外链，仅限候选阶段；正式实现要本地托管。

### A 日刊（待改）
- 拉丁展示字体 Fraunces 属于禁用默认，换成 Playfair Display（意大利体 900 用于名次）。
- 暖米色、朱红、近黑棕的组合接近套路配色，换成更冷的新闻纸色：底 #EFEEE9、次底 #E6E4DC、墨 #151515、次墨 #3A3A38、灰 #75736C、红 #D23B1F。
- 报头的“No. 214”是装饰性假期号，删掉，改为“GitHub 快速中心 / 每日更新”。
- 窗口下划线不再动画 width，改为基准 100px，用 translateX 加 scaleX。

### B 星图（待改）
- 辉光过多：去掉名次和品牌字的 text-shadow，只保留星轨末端和第 1 名的辉光。
- 星轨原来是非线性比例（log 的三次方），会夸大小项目、误导对比。改为相对第 1 名的线性比例（最短 3%），去掉背景轨道。星轨用 scaleX、末端用 translateX 动画，不再动画 width。
- 标题“今天谁在发光”在近 30 天下说不通，改为“涨星榜”。
- 星空和 FLIP 在减少动态效果下改为静态。

### C 信号（待改）
- 信号色 #FF4F12 饱和度为 100%，改为 #E25A2B（约 76%）。
- 未选中标签里的“天”字被描边叠压，改为实心灰色，选中时为墨色。
- 行悬停原来动画 padding，改为对前两列用 transform: translateX(10px)。
- 窗口滑块改为 translateX 加 scaleX。
