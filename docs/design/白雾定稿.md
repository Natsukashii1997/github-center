## 3. 涨星榜首页（`r7.html`）

### 报头

- 小字行：`GitHub · 近 1 天 · 10/23`（随窗口变）+ 数据新鲜度圆点。
  - 新鲜：绿点「数据是最新的」；过期：黄点「已 N 天没有新数据」。悬停显示更新时间原文。
- 大标题「涨星榜」。口径说明（统计日、全站 N 个候选、官方核数 N 次）只放在标题的悬停说明里。
- 右侧四格读数（这就是「本期看点」，不另写一句话）：
  - 第一名：项目名（可点，打开详情栏）+ 小字「蝉联第一 N 期」或「本期登顶」。
  - 新面孔：N 个 + 最多 6 个头像（可点）。没有上一期时写「暂无上一期」。
  - 飙升最多：项目名（可点）+ 绿色「▲N」。没有时写「暂无名次变化」。

- 底边：类型构成色带（按定义标签分段，段长按个数）+ 右侧图例（类型名 + 个数）。点色带一段或图例一项就按该类型筛选，再点取消；选中时其余段变淡。
