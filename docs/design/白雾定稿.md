## 2. 全站共用

- **只做桌面版**，不做窄屏适配。
- **背景**：牛马之家登录页的 ASCII 鲨鱼（`niuma-home/src/vendor/ascii-sharks`，MIT），反色成浅色，铺满全屏、固定不动；上面叠一层中间浓、四周淡的白雾。整体向它靠拢。
- **气质**：GitHub 风格（GitHub 色系、Primer 式按钮和分段控件），不照搬牛马之家的终端样式。所有页面按同一风格。
- **信息要密、要细**，不要又大又空。
- **顶栏**：高 50px，半透明白底加模糊。
  - 左：品牌「★ GitHub 快速中心」（★ 在黑色小圆里）。
  - 中：导航三项「涨星榜／分类榜／我的收藏」，当前页加粗加淡灰底。日报已删。
  - 右：搜索框（240px，placeholder「搜项目名、标签、用途」，右侧 `/` 键帽）+ 账号头像圆点。
- **内容宽度**：`min(1180px, 100% - 48px)` 居中。
- **滚动**：
  - 涨星榜首页：整页不滚，只有榜单盒子内部滚动。
  - 分类榜、我的收藏：整页滚动，顶栏吸顶；页面底部留 30vh 空白不放内容，让鲨鱼游过去。不放页脚。
- **报头（C 报头，三页共用）**：没有框，大标题直接压在白雾上，四周一圈白色柔光。
  - 左：一行英文大写小字（`GitHub · 页面 · 日期`），下面 38px、800 粗的中文标题。
  - 右：一排读数，用细竖线隔开，每格是小字标签 + 15px 数值。
  - 底边一条横带当分隔线（首页是类型构成色带，另两页是 5px 渐变色带）。
- **三种标签**（全站同一套定义）：
  - 说明标签：几个字说明属于什么，如「逆向拆解」「界面设计」。浅蓝底 `#ddf4ff`、深蓝字 `#0550ae`。
  - 定义标签：说明它是什么，**固定取值** Skill、MCP、Agent、AI 应用、插件、框架、工具、应用、内容。白底细框、等宽字，左边一个类型色小方块。类型色：Skill `#8250df`、MCP `#0f8f8a`、Agent `#0969da`、AI 应用 `#bf3989`、插件 `#9a6700`、框架 `#1a7f37`、工具 `#57606a`、应用 `#bc4c00`、内容 `#8a6a4a`。
  - 状态标签：放在星数旁边，每项最多一个，优先级 蝉联第一 N 期 ＞ 首次上榜 ＞ 飙升 N 名（上升 ≥5 名）＞ 在榜 N 期。配色：蝉联第一黄底带 ♛、首次上榜红底带 ●、飙升紫底带 ↑、在榜多期灰底。
- **名字**：主名字用项目名（如 rea），作者名只做小字（等宽灰字）。
- **复制安装指令**：复制的是一段交给 AI 的中文请求（装哪个项目或哪个 Skill，只依据项目文档和官方文档操作，缺账号、密钥或要付费时停下来说）。点了按钮变绿显示「已复制 ✓」约 1.4 秒。正式文案「见文末判定」。
- **柱图**：纵轴从零起、线性；缺数据的那天留空位，不补零；灰柱 `#c9d1d9`，最后一天用强调蓝 `#0969da`。

## 3. 涨星榜首页（`r7.html`）

### 报头

- 小字行：`GitHub · 近 1 天 · 10/23`（随窗口变）+ 数据新鲜度圆点。
  - 新鲜：绿点「数据是最新的」；过期：黄点「已 N 天没有新数据」。悬停显示更新时间原文。
- 大标题「涨星榜」。口径说明（统计日、全站 N 个候选、官方核数 N 次）只放在标题的悬停说明里。
- 右侧四格读数（这就是「本期看点」，不另写一句话）：
  - 第一名：项目名（可点，打开详情栏）+ 小字「蝉联第一 N 期」或「本期登顶」。
  - 新面孔：N 个 + 最多 6 个头像（可点）。没有上一期时写「暂无上一期」。
  - 飙升最多：项目名（可点）+ 绿色「▲N」。没有时写「暂无名次变化」。
  - 最多的类型：类型名 + `n / 20`。
- 底边：类型构成色带（按定义标签分段，段长按个数）+ 右侧图例（类型名 + 个数）。点色带一段或图例一项就按该类型筛选，再点取消；选中时其余段变淡。

## 6. 我的收藏（`fav.html`）

- 收藏的是项目或单个 Skill，跟账号走；主要用途是复制安装指令交给自己的 AI。
- 报头：小字 `GitHub · 我的收藏 · 账号名`，标题「我的收藏」；右侧三格「项目 N 个」「Skill N 个」「最近收藏 M/D」（只读，不可点）。
- **布局：C 收藏架**。左边侧栏 228px，右边书架。
  - 书架按类别分组，组按收藏数从多到少排；每组标题是类别名 15px + 数量。
  - 项目按它的第一个类别归组；单个 Skill 的收藏全部归「Skill」组。
  - 每组卡片网格，每张最小 220px 自动换行，间距 10px。
- **侧栏：A 只留类别目录**。
  - 淡玻璃底（不让鲨鱼透到字上），吸顶（顶栏下方）。

## 8. 每页需要的数据字段

来源说明：**已有** = 现有数据或项目资料里已经有；**补资料** = 要在 Codex 补资料那一步生成；**推出** = 由已有字段算出；**新数据源** = 要新接数据。

### 涨星榜首页、详情栏、项目页

- 榜单级：窗口名 `label`、统计日、口径（`span`、候选数、核数次数）、更新时间文本 —— 已有
- 名次 `rank`、本期涨星 `gain`、三个窗口涨星 `gains.d1/d7/d30`、总星 `total` —— 已有

- 状态标签 —— 推出（由 `mv`、`streak` 按第 2 节优先级算）

## 实现时的判定（2026-11-03，Claude）

- 文案按原型：没有上一期时写「暂无上一期」「暂无名次变化」；报头是四格读数（第一名、新面孔、飙升最多、最多的类型），不另加「本期看点」句子。
- 详情栏保留原型顶部（身份、标签含语言、一句话、四格读数、30 天柱图），下面四段：主要用途、使用场景、包含 Skill、项目信息。不放「做什么 / 解决什么问题 / 使用条件」。
- 前三卡描述按原型保留「做什么 + 解决什么问题」连写；行里只放一句话和「做什么」。
- 搜索：照 placeholder「搜项目名、标签、用途」，正式版把主要用途、使用场景也纳入；只在本页列表里过滤。分类榜、我的收藏页顶栏搜索同样只过滤本页内容。
- 项目信息顺序：语言、创建于 · 上线 N 天、分类、最近更新（最近推送日期）、最新版本（版本号 · 发布日期；没发过写「还没发过正式版」）。
- Claude Code／Codex 切换：复制内容沿用现有 `src/profiles/install.js` 的两种指令；文案也用它。
- 项目页 `/p/`：整页显示详情栏内容（中间一块面板）。首页、分类榜、收藏页里点项目在本页右侧打开详情栏；外部链接和直接访问用 `/p/`。
- 热点榜：按原型不做分类筛选（只有历史榜有）。走势不满 7 天时，副行写「记录不满 7 天（已记 N 天）」。
- 说明标签、定义标签：**不推导**，和一句话、用途、场景一起由 Codex 生成；定义标签必须是固定取值之一（推翻需求补数据方案第 1 条里「由分类推出」的写法）。
- 收藏丝带颜色按原型：取所属项目的第一个类别色，Skill 收藏也一样。
- 历史榜里不在候选中的项目：同样生成项目资料（一句话、类别），生成前先显示 GitHub 原始描述。
