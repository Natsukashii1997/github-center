原实验库保留65,935个候选。8个星数漂移已在隔离副本找到处理方案，1个空项仍阻止完整枚举；采集尚未恢复。AI日报只完成过小样本生成，界面、账号、收藏、安装指令和团队邀请仍待产品实现。

## 本地使用

1. 克隆此私有仓库并阅读上面的当前状态与产品范围。
2. 如只查资料，不需要安装依赖。
3. 如核验已归档的采集逻辑，使用已有Python运行：

```sh
python3 scripts/check_offline.py
```

检查在临时副本使用假数据和模拟请求，不读取真实运行库，不发GitHub采集请求。看到全部5组检查PASS才表示这些离线检查通过；它不代表真实全站采集完成。当前已验证的Python版本和结果见[建仓核验](docs/verification/bootstrap.md)。

不要直接运行研究目录中的start_worker.py或恢复验证器。它们仍依赖原实验的运行计划或未入库证据；需要恢复真实实验时先核验原目录状态与完整性门禁。
